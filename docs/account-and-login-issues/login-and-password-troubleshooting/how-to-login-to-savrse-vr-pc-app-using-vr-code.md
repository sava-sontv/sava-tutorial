### Learn how to use a temporary code to securely log in to the Savrse VR or PC App

You can securely log in to the Savrse VR App or Savrse PC App by entering a temporary login code on the Community page.

This method allows you to sign in without entering your email address and password directly on your VR headset or PC App.

**Important:** Make sure you are signed in to the correct Sava Account on the Savrse Community website. The same account will be used to log in to the VR or PC App.

**Before You Begin, make sure that:**

* You have installed and opened the latest version of the Savrse VR App or Savrse PC App.
* Your device is connected to the internet.
* You have access to a web browser on your computer or mobile device.
* You have an active Sava Account.

***Step 1: Get a Login Code from the VR or PC App***

1. Open the Savrse VR App or Savrse PC App.
2. On the login screen, select the **Code** tab.
3. A six-character login code will appear on the screen.
4. Keep the app open while completing the login process.

The countdown under the code shows how long the code remains valid.

!\[Image 1 – Login code displayed in the Savrse App](/images/login-by-code.webp)

**Note:** Each login code is temporary and can only be used one time.

***Step 2: Open the VR Code Page***

1. Open a web browser on your computer or mobile device.
2. Go to savrse.savameta.com
3. Sign in using your Sava Account.
4. From the Savrse Community page, select **VR Code**.

The Input Code page will be displayed.

Make sure you sign in with the Sava Account that you want to use in the Savrse VR or PC App.

***Step 3: Enter the Login Code***

1. Enter the six-character code displayed in the Savrse App.
2. Check that all letters and numbers have been entered correctly.
3. Select **Login**.

!\[Image 2 – Entering the code on Savrse Community](/images/input-code.webp)

***Step 4: Return to the Savrse App***

After the code is successfully verified:

1. Return to your VR headset or the Savrse PC App.
2. The app will automatically complete the login process.
3. You can then access Savrse using the Sava Account selected on the website.

Do not close the Savrse App until the login process has been completed.

**Get a New Login Code**

When the countdown reaches zero, the current code expires and can no longer be used.

To generate another code:

1. Return to the login screen in the Savrse VR or PC App.
2. Select **Get New Code**.
3. Enter the new code on the VR Code page.
4. Select **Login** again.

Only the most recently generated code should be used.

**Security Tips**

* Do not share your login code with anyone.
* Only enter the code on the official Savrse website.
* A login code is temporary and intended for one-time use.
* Confirm that the correct Sava Account is signed in before submitting the code.
