### Troubleshoot login failures when using Login by Code in VR App

When you select Log in by Code on the VR App, you’ll receive a one-time code that must be entered on the Community (in the VR Code section).

If you see the toast message “Something went wrong”, the login process could not be completed.

**Common Reasons & Quick Fixes**

1. Community Session Timeout

If your web session expires or you are not logged in with a valid session, the verification may fail.

Fix:

* Refresh the browser
* Log out → Log in again on the Community
* Re-enter the code

2. VR App Code Invalid After System Error

In some cases, the VR App may generate a code that appears valid, but the system cannot verify it.

Fix:

* Manually close the VR App completely
* Reopen VR App
* Generate a new login code
* Enter the new code on the Community

3. The VR App Lost Connection Before Verification

If your VR device disconnects from the internet while generating or waiting for the code, the code becomes invalid.

Fix:

* Ensure your VR headset has a stable internet connection.
* Restart the VR App and generate a new code.

4. Server or Network Issue

Temporary server delays or an unstable network may interrupt code verification.

Fix:

* Wait 1–2 minutes and try again
* Switch to a stronger Wifi or mobile network
* Try a different browser if possible

**When to Contact Support**

If none of the above solutions work, contact our Support Team (savrsesupport@savameta.com).
Please include:

* A screenshot of the VR App login code
* A screenshot of the “Something went wrong” message
* Your device model (VR headset)
* Approximate time of the login attempt

This helps us diagnose whether the issue is related to your account, device, or system.
