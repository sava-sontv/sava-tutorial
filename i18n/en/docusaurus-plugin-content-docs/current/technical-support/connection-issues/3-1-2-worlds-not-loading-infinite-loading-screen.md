Worlds may fail to load or remain stuck on Loading Screen

**Common Reasons**

* Slow or unstable internet
* Server load or temporary world instability
* Timeout when retrieving world assets

**How to fix?**

* Restart the VR App and try a different world first
* Switch to a faster or more stable network
* Move closer to the Wifi router
* Restart your headset to refresh cached data

If all worlds fail to load, it may be a platform-wide issue.
