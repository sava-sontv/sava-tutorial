title: World Takes Too Long to Load
slug: world-takes-too-long-to-load

---
If a world loads unusually slowly or appears stuck on the loading screen, it may indicate network delays, insufficient device resources, or heavy world objects.

**Common Causes**

* Slow internet speed
* World contains large textures, objects, or media
* Device memory nearly full
* Network blockage by VPN or firewall

**How to Fix**

* Check your Wifi or switch to a faster connection: World loading relies heavily on stable bandwidth.
* Close other apps: Free up resources required to load large environments.
* Restart your VR device: This helps clear memory and resolve stuck loading screens.
* Try loading a different world: If other worlds load normally, the issue is likely world-specific.

**Still Need Help?**

Contact Support with the world name and your device model for further investigation.
