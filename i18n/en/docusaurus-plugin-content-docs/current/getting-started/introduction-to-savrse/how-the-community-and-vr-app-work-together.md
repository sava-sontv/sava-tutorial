Although the VR App is where you play the game, the Community provides management tools and a familiar panel UI that mirrors the interface inside VR.

**Key Differences**

| Feature                            | Community | VR App |
| ---------------------------------- | --------- | ------ |
| Login / Register / Forgot Password | ✓         | ✓      |
| Login as Guest                     | ✗         | ✓      |
| Browse Worlds, Avatars, Users      | ✓         | ✓      |
| Join Worlds                        | ✗         | ✓      |
| Avatar Creation & Editing          | ✗         | ✗      |
| Social Features                    | ✓         | ✗      |
| Notification                       | ✓         | ✓      |
| Global Search                      | ✓         | ✓      |
| VR Settings                        | ✗         | ✓      |
| Account Setting (My Account)       | ✓         | ✗      |



**How Data Syncs**

* All data will be synced automatically across both platforms.
* Example: If you change your avatar on Community, it will be updated in VR App once you log in or refresh main panel
