### Explanation of which device user can use to enjoy Savrse, including device requirements

**VR App Requirements**

* Supported VR Devices:

  * Meta Quest 3S
  * Meta Quest 3
  * Meta Quest Pro
* Recommended:

  * Ensure at least 565MB free storage to download and install
  * Use stable Wi-Fi to avoid download interruptions

**Community & Creator Hub Requirements**

* Any modern browser (Chrome, Edge, Firefox, Safari,...)
* Stable internet connection

**Savrse Studio Requirements**

* Minimum:

  * OS: Windows 7 SP1+ (64-bit)
  * CPU: SSE2 (Core 2 Duo / i3-2100)
  * RAM: 4GB
  * GPU: DX10 (GT 8600 / HD 2600 / HD 3000, 512MB)
  * Storage: 10 GB HDD
* Recommended:

  * OS: Windows 10/11 64-bit
  * CPU: Quad-core 2.5GHz+ (i5-4xxx / Ryzen 3)
  * RAM: 8GB
  * GPU: DX11 (GTX 750 Ti / RX 550, 2GB)
  * Storage: SSD 256GB+
