### A beginner’s guide to building your first virtual world using Savrse Studio

Creating a World in Savrse involves three steps:

1. Building the in-world environment using **Savrse Studio** with templates or projects.
2. Publishing projects from **Savrse Studio** to **Creator Hub**.
3. Creating the World metadata on the **Creator Hub**.

***Step 1: Build Environment (Savrse Studio)***

1. Open Savrse Studio and log in.
2. Create a new project or Edit on a project  you created.
3. Begin building the environment:

   * Place objects
   * Adjust lighting
   * Add environment elements
   * Configure interactions or triggers
4. When building project is completed, Click Save to update the current version of the project.
5. Click Publish to release project on Creator Hub

**Result:** 

* The project version is submitted to the system for release.
* The published project will be synced to Creator Hub and enter the Review process.

**Note:** 

* Project and Version data in Savrse Studio are automatically synced with Creator Hub.
* Saving a project only updates the version internally.
* Only published versions can be used to create a World.

***Step 2: Project Review & Release (Creator Hub)***

1. Go to **[Creator Hub](https://savrse.savameta.com/creator-hub/)**.
2. Select Release.
3. View the list of published projects and their review status.

**Review Status Definitions:**

* In Review: The project is being reviewed by the system/moderation team.
* Failed:

  * The project does not meet review requirements.
  * The project cannot be used to create a World.
  * The creator must return to Savrse Studio, update the project, and publish a new version.
* Published:

  * The project has passed the review process.
  * The project version is officially released.
  * The project can now be selected when creating World metadata.

**Important Rule:** Only projects with status Published are available for World creation.

***Step 3: Create World Metadata (Creator Hub)***

1. Go to **[Creator Hub](https://savrse.savameta.com/creator-hub/)**.
2. Select Worlds.
3. Click Create World
4. Fill in the required fields:

   * World Name
   * Thumbnail Image
   * Description
   * Tags
   * Project (Only projects with status Published are selectable)
   * Version (Only Published version of the project are selectable)
5. Click Save to create your World Metadata.

**Result:**

* A new World is created using the published project version.
* The World is now available for discovery and access based on system.
