Experiencing delayed movement, voice lag, or players teleporting?

**Reasons**

* High latency or packet loss
* Overcrowded Wifi environment
* Network throttling on public Wifi
* Router too far from your VR device

**How to fix?**

* Use a 5 GHz Wifi network instead of 2.4 GHz
* Limit other devices using the same network
* Restart router
* Avoid using public Wifi hotspots
* If possible, connect router via ethernet for maximum stability
