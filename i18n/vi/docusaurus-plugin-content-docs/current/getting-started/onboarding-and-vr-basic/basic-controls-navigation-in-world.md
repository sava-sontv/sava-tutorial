### How to move, teleport, and interact with objects using VR controllers

Navigation controls vary slightly depending on the VR headset, but the basics are consistent across devices. Learn the essential controls to move around, interact with menus, and communicate.

**Movement**

* Left joystick: Walk / move
* Right joystick: Turn camera
* Trigger (index finger press): Select / Interact
* Grip (middle finger press): Pick Up
* Open VR Panel: Y button
* Open Action Menu: B button

**Interaction**

* Point raycast at UI elements using controller
* Press trigger to confirm actions
* Grip button to pick up objects (if supported in world)

**Voice Chat**

* Auto-enabled with proximity
* Mute/unmute via Settings

**Comfort Settings (will update in the future):**

You can adjust in VR Settings

* Turning method (smooth vs snap)
* Movement mode
* Headset vibration
* Brightness & UI scale

These options help reduce motion sickness and improve comfort.
