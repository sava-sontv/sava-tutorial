# Luồng Sidebar, Sinh Bài viết, Sắp xếp và Ẩn/Hiện

Tài liệu mô tả cách project sinh sidebar, quản lý bài viết (.md), sắp xếp thứ tự và ẩn/hiện category/bài viết.

---

## 1. Tổng quan luồng

Khi chạy **`yarn dev`** hoặc **`yarn build`**, các bước chạy theo thứ tự:

```
┌─────────────────────────┐
│  yarn dev / yarn build  │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐     ┌──────────────────────────────────┐
│ ensure-category-json.js │────►│ docs/<folder>/_category_.json    │  (Docusaurus: label, position, link)
│                             │ docs/<folder>/_category.json      │  (active, sort)
│                             │ src/data/categories.generated.ts  │
└───────────┬─────────────┘     └──────────────────────────────────┘
            │
            ▼
┌─────────────────────────┐     ┌──────────────────────────────────┐
│ apply-articles-json.js  │────►│ docs/<folder>/_articles.json      │  (id, active, sort cho từng bài)
│ (chỉ chạy lúc đầu)      │     │ Tự thêm bài mới nếu có file .md   │
└───────────┬─────────────┘     └──────────────────────────────────┘
            │
            ▼
┌─────────────────────────┐     ┌──────────────────────────────────┐
│ generate-sidebar.js     │────►│ sidebars.autogenerated.js        │  (Docusaurus đọc file này)
│ Đọc _category.json +    │     │ Thứ tự category & bài theo sort   │
│ _articles.json         │     │ Chỉ đưa vào sidebar nếu active    │
└───────────┬─────────────┘     └──────────────────────────────────┘
            │
            ▼
┌─────────────────────────┐
│ sync-docs-i18n.js       │────► Copy docs/ sang i18n/vi/... (md, _category_.json)
└─────────────────────────┘
```

- **Watcher** (khi `yarn dev`): theo dõi `_category.json` và `_articles.json`. Khi bạn sửa → tự chạy lại **ensure-category-json** (nếu đổi category) và **generate-sidebar** + **sync-docs-i18n** → sau đó **restart process Docusaurus** để nó đọc lại `sidebars.autogenerated.js` → **sidebar cập nhật ngay** trên giao diện (không cần bạn tự tắt và chạy lại `yarn dev`).

## 2. Generate Sidebar (generate-sidebar.js)

### 2.1 Mục đích

- **Đầu vào:** Cấu trúc thư mục `docs/` + file `_category.json` và `_articles.json` trong từng folder.
- **Đầu ra:** File `sidebars.autogenerated.js` — Docusaurus dùng file này để hiển thị sidebar.

### 2.2 Luồng generate-sidebar

1. Duyệt mọi folder con trong `docs/` (chỉ folder có ít nhất một file `.md`/`.mdx`).
2. Với mỗi folder:
   - Đọc **`_category.json`** → lấy `active`, `sort`.
   - Nếu **`active === false`** → **bỏ qua** folder (không đưa vào sidebar).
   - Đọc **`_articles.json`** → danh sách bài với `id`, `active`, `sort`.
   - Lấy danh sách file `.md`/`.mdx` trong folder; với mỗi file:
     - Nếu có trong `_articles.json` và **`active === false`** → không đưa vào sidebar.
     - Nếu không có trong JSON → mặc định **active** (vẫn hiện), sort = 999.
   - Sắp xếp bài trong folder theo **`sort`** (số nhỏ = lên trước).
3. Sắp xếp **các category** theo **`sort`** trong `_category.json` (số nhỏ = lên trước).
4. Ghi ra **`sidebars.autogenerated.js`** với cấu trúc Docusaurus (category + items là docId dạng `folder/doc-id`).

**Kết luận:** Thứ tự và ẩn/hiện sidebar **do `_category.json` và `_articles.json` quyết định**, không do frontmatter trong `.md`.

## 3. Sinh / Cập nhật bài viết (apply-articles-json.js)

### 3.1 Mục đích

- Đảm bảo mỗi folder trong `docs/` có file **`_articles.json`**.
- **Tự thêm** bài mới vào JSON khi bạn tạo file `.md`/`.mdx` mới (chạy script lại hoặc qua watcher không tự chạy apply-articles-json khi thêm file — watcher chỉ theo dõi thay đổi `_articles.json`; thêm file .md mới thường cần chạy tay `yarn apply-articles-json` hoặc chạy `yarn dev` từ đầu).

**Lưu ý:** Trong `yarn dev`, **apply-articles-json chỉ chạy một lần lúc khởi động**. Watcher chỉ theo dõi `_category.json` và `_articles.json`, không theo dõi file `.md` mới. Nếu bạn **thêm file .md mới** khi dev đang chạy, cần tự chạy `yarn apply-articles-json` (hoặc thêm tay entry vào `_articles.json`) rồi chạy `yarn generate-sidebar`; hoặc restart `yarn dev` để apply-articles-json chạy lại.

### 3.2 Cấu trúc _articles.json

Mỗi **`docs/<folder>/_articles.json`** là một mảng:

```json
[
  { "id": "tên-file-không-có-đuôi", "active": true, "sort": 5 },
  { "id": "bai-khac", "active": false, "sort": 10 }
]
```

- **id:** Tên file không có đuôi (ví dụ `new-world.md` → `"new-world"`).
- **active:** `true` = hiện trên sidebar, `false` = ẩn.
- **sort:** Số càng nhỏ = càng lên trước trong sidebar (thường dùng bước 5: 5, 10, 15, 20...).

### 3.3 Khi nào script thêm bài mới?

- Khi chạy **apply-articles-json**: script quét mọi file `.md`/`.mdx` trong folder. File nào **chưa có** trong `_articles.json` sẽ được **thêm** với `active: true` và `sort` = (maxSort hiện tại + 5).
- Script **không xóa** entry trong `_articles.json` khi bạn xóa file .md. Khi generate-sidebar chạy, nó chỉ đưa vào sidebar những file .md **thực sự tồn tại** trong folder; nếu file .md đã xóa thì bài đó sẽ không còn trên sidebar (bạn có thể xóa tay entry trong `_articles.json` cho gọn).

## 4. Sắp xếp (sort)

### 4.1 Sắp xếp category (folder trên sidebar)

| File cần sửa | Trường | Ý nghĩa |
|--------------|--------|--------|
| **`docs/<folder>/_category.json`** | **`sort`** | Thứ tự folder trên sidebar. Số **nhỏ hơn** = hiển thị **cao hơn** (trên cùng). |

Ví dụ: Muốn "Worlds" lên đầu → đặt `"sort": 1` trong `docs/worlds/_category.json`, các folder khác dùng số lớn hơn (5, 10, 15...).

Sau khi sửa:
- Chạy **`yarn ensure-category-json`** → cập nhật `_category_.json` (position) và `categories.generated.ts`.
- Chạy **`yarn generate-sidebar`** → sidebar đổi thứ tự category.
- Hoặc đang chạy **`yarn dev`** thì watcher sẽ tự chạy hai bước trên khi bạn sửa `_category.json`.

### 4.2 Sắp xếp bài viết trong từng folder

| File cần sửa | Trường | Ý nghĩa |
|--------------|--------|--------|
| **`docs/<folder>/_articles.json`** | **`sort`** của từng phần tử | Thứ tự bài trong folder. Số **nhỏ hơn** = hiển thị **cao hơn** trong sidebar. |

Ví dụ: Muốn `new-world.md` lên đầu trong folder Worlds → trong `docs/worlds/_articles.json` đặt `"sort": 1` cho entry `"id": "new-world"`, các bài khác dùng số lớn hơn.

Sau khi sửa: chạy **`yarn generate-sidebar`** (hoặc để watcher tự chạy khi `yarn dev`).

---

## 5. Ẩn / Hiện (active)

### 5.1 Ẩn hoặc hiện cả một category (cả folder)

| File cần sửa | Trường | Ý nghĩa |
|--------------|--------|--------|
| **`docs/<folder>/_category.json`** | **`active`** | `true` = folder hiện trên sidebar, `false` = **ẩn hẳn** folder (không hiện trong sidebar). |

Sau khi sửa: chạy **`yarn ensure-category-json`** và **`yarn generate-sidebar`** (hoặc để watcher làm khi `yarn dev`).

### 5.2 Ẩn hoặc hiện từng bài viết

| File cần sửa | Trường | Ý nghĩa |
|--------------|--------|--------|
| **`docs/<folder>/_articles.json`** | **`active`** của từng phần tử | `true` = bài hiện trong sidebar, `false` = **ẩn** bài (không xóa file .md, chỉ không hiện trong sidebar). |

Sau khi sửa: chạy **`yarn generate-sidebar`** (hoặc để watcher làm khi `yarn dev`).

---

## 6. Tóm tắt file và lệnh

| Việc cần làm | File sửa | Lệnh (nếu không dùng yarn dev) |
|--------------|----------|--------------------------------|
| Đổi thứ tự **category** (folder) | `docs/<folder>/_category.json` → `sort` | `yarn ensure-category-json` + `yarn generate-sidebar` |
| Ẩn/hiện **category** | `docs/<folder>/_category.json` → `active` | `yarn ensure-category-json` + `yarn generate-sidebar` |
| Đổi thứ tự **bài** trong folder | `docs/<folder>/_articles.json` → `sort` từng bài | `yarn generate-sidebar` |
| Ẩn/hiện **bài** | `docs/<folder>/_articles.json` → `active` từng bài | `yarn generate-sidebar` |
| Thêm bài mới (file .md) | — | Chạy `yarn apply-articles-json` (rồi `yarn generate-sidebar` nếu cần), hoặc thêm tay vào `_articles.json` |

Khi chạy **`yarn dev`**, watcher theo dõi `_category.json` và `_articles.json`: sửa xong chỉ cần lưu file, sidebar sẽ tự cập nhật (sau khi ensure-category-json / generate-sidebar chạy xong). Dừng dev: **Ctrl+C**.
