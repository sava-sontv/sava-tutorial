# Cách Docusaurus chạy và generate docs trong project này

## 1. Cấu hình Docusaurus (`docusaurus.config.ts`)

- **Preset classic** với:
  - **Docs**: `sidebarPath: './sidebars.autogenerated.js'` → sidebar **không** dùng autogenerated mặc định của Docusaurus mà dùng file do script tạo.
  - **Blog**: tắt (`blog: false`).
- **i18n**: 2 locale `en` (mặc định) và `vi`.
- **URL**: `http://savrse.savameta.local:3000/help`, port 3000 (baseUrl `/help/`).

Docs mặc định nằm ở thư mục **`docs/`** (path mặc định của preset classic).

---

## 2. Luồng chạy khi dev và build

### Khi chạy `yarn dev` / `yarn start` (`scripts/start-with-watch.js`)

1. **Chạy lần đầu (trước khi start Docusaurus):**
   - `ensure-category-json.js` → tạo/cập nhật `_category_.json`, `_category.json`, `categories.generated.ts`
   - `apply-articles-json.js` → tạo/cập nhật `_articles.json` trong từng folder docs
   - `generate-sidebar.js` → sinh `sidebars.autogenerated.js` từ `_category.json` + `_articles.json`
   - `sync-docs-i18n.js` → copy `docs/` sang `i18n/vi/docusaurus-plugin-content-docs/current/`

2. **Start Docusaurus:**  
   `npx docusaurus start --host savrse.savameta.local --port 3000`

3. **Watcher (chokidar):**  
   Theo dõi mọi `_category.json` và `_articles.json` trong `docs/`. Khi có thay đổi:
   - Nếu đổi `_category.json`: chạy lại ensure-category-json → generate-sidebar → sync-docs-i18n → **touch** `sidebars.autogenerated.js`
   - Nếu đổi `_articles.json`: chạy lại generate-sidebar → sync-docs-i18n → touch sidebar  
   Touch sidebar khiến Docusaurus dev server đọc lại config → sidebar và giao diện cập nhật (hot reload).

### Khi chạy `yarn build`

Thứ tự cố định:

```
yarn ensure-category-json
→ yarn apply-articles-json
→ yarn generate-sidebar
→ yarn sync-docs-i18n
→ docusaurus build
```

Tức là: trước khi **build**, project luôn regenerate category, articles, sidebar và sync i18n, rồi mới gọi `docusaurus build`.

---

## 3. Cách "generate" docs trong project này

Docs **không** được "generate" từ nguồn khác (API, CMS…) mà là **file Markdown có sẵn** trong `docs/`. "Generate" ở đây là:

- Generate **cấu trúc** (sidebar, category, i18n) từ các file JSON trong `docs/`, **không** generate nội dung `.md`.

### Cấu trúc mỗi folder trong `docs/` (vd: `docs/avatars/`)

| File | Mục đích |
|------|----------|
| `_category_.json` | Cho Docusaurus: label, position, link (generated-index). Script `ensure-category-json.js` ghi file này. |
| `_category.json` | Meta của project: `active` (hiện/ẩn category), `sort` (thứ tự). Dùng bởi `generate-sidebar.js` và `categories.generated.ts`. |
| `_articles.json` | Danh sách bài trong folder: `id`, `active`, `sort`. Script `apply-articles-json.js` tự thêm bài mới; bạn chỉnh thứ tự/ẩn hiện ở đây. |
| `*.md` / `*.mdx` | Nội dung doc thật. Docusaurus đọc trực tiếp từ đây. |

### Luồng dữ liệu

```
docs/<folder>/
  _category_.json (Docusaurus)
  _category.json  (active, sort) ──┐
  _articles.json  (id, active, sort) ──┼──► generate-sidebar.js ──► sidebars.autogenerated.js
  *.md / *.mdx (nội dung)             │
                                      └──► ensure-category-json.js ──► categories.generated.ts
                                                                     + _category_.json
```

- **Docusaurus** đọc:
  - Nội dung từ `docs/**/*.md|.mdx`
  - Sidebar từ `sidebars.autogenerated.js`
  - Category từ `docs/<folder>/_category_.json`
- **Project** đọc thêm:
  - `_category.json` và `_articles.json` để tạo sidebar và (nếu cần) trang chủ / danh sách category trong `src/data/categories.generated.ts`.

## 4. Chuyển bài viết / section sang category hoặc section khác

Mục đích: **khi chuyển bài viết ra sections hoặc categories khác thì không lỗi**.

- **Path** (`/categories/id-slug`, `/sections/id-slug`, `/articles/pathId-slug`) **không phụ thuộc** vị trí thư mục trong `docs/`. `id` và `pathId` lấy từ slug hoặc từ `_category.json` / `_articles.json`.
- Sau khi **di chuyển** file `.md` (hoặc cả folder section) trong `docs/`:
  1. Cập nhật `_articles.json` trong folder **đích** (thêm entry bài với `id` = tên file không đuôi; nếu muốn giữ URL cũ thì copy `pathId` từ entry cũ).
  2. Chạy **`yarn ensure-category-json`** và **`yarn generate-sidebar`** (hoặc `yarn dev` / `yarn build` sẽ tự chạy).
- Script build lại `pathToDocPath.json` và `docPathToPath.json` theo **cấu trúc docs/ hiện tại** → redirect và link sidebar/breadcrumb vẫn đúng, không lỗi.

---

## 5. i18n (tiếng Việt)

- **sync-docs-i18n.js** copy toàn bộ `docs/` (kể cả `.md`, `_category_.json`, `_category.json`, `_articles.json`) sang `i18n/vi/docusaurus-plugin-content-docs/current/`.
- Hiện tại locale **vi** dùng chung nội dung với **en** (không dịch riêng), chỉ khác đường dẫn locale (`/vi/docs/...`).

---

## 6. Tóm tắt lệnh và file quan trọng

| Lệnh | Chức năng |
|------|------------|
| `yarn dev` / `yarn start` | Chạy 4 script rồi start Docusaurus + watch `_category.json` & `_articles.json` → auto regenerate sidebar. |
| `yarn build` | ensure-category-json → apply-articles-json → generate-sidebar → sync-docs-i18n → `docusaurus build`. |
| `yarn ensure-category-json` | Tạo/cập nhật `_category_.json`, `_category.json`, `src/data/categories.generated.ts` theo từng folder có `.md`. |
| `yarn apply-articles-json` | Tạo/cập nhật `_articles.json` (thêm bài mới từ file .md). |
| `yarn generate-sidebar` | Đọc `_category.json` + `_articles.json` → ghi `sidebars.autogenerated.js`. |
| `yarn sync-docs-i18n` | Copy `docs/` → `i18n/vi/.../current/`. |

**Kết luận:** Docusaurus chạy như site docs chuẩn (đọc `docs/` + sidebar), còn "generate docs" trong project là **generate cấu trúc sidebar và category từ JSON** (`_category.json`, `_articles.json`) qua các script trên, không generate nội dung Markdown.
