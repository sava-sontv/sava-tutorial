# File cần thiết trong thư mục i18n cho docs

## Trong `i18n/vi/docusaurus-plugin-content-docs/current/`

| File | Cần thiết? | Lý do |
|------|------------|--------|
| **`*.md` / `*.mdx`** | **Có** | Nội dung docs cho locale vi. Docusaurus đọc từ đây để hiển thị `/vi/docs/...`. |
| **`_category_.json`** | **Nên có** | Docusaurus dùng cho nhãn category và trang generated-index (title, description) theo locale. Nếu muốn tiêu đề category tiếng Việt trên trang index (vd. /vi/docs/avatars), nên giữ và dịch `label`, `link.title`, `link.description` trong file này. |
| **`_category.json`** | **Không** | Chỉ dùng bởi script trong project (ensure-category-json, generate-sidebar), và các script chỉ đọc từ **`docs/`**, không đọc từ i18n. Sidebar được sinh một lần từ `docs/` → `sidebars.autogenerated.js` dùng chung cho mọi locale. |
| **`_articles.json`** | **Không** | Cùng lý do: chỉ script (apply-articles-json, generate-sidebar) đọc từ **`docs/`**. Không có script hay Docusaurus nào đọc `_articles.json` trong thư mục i18n. |

## Kết luận

- **Bắt buộc trong i18n:** chỉ **nội dung docs** (file `.md` / `.mdx`).
- **Nên có nếu dịch nhãn category:** `_category_.json` trong từng folder (để tiêu đề/description trang index tiếng Việt).
- **Không cần sinh/đồng bộ vào i18n:** `_category.json` và `_articles.json` — có thể bỏ qua khi sync để thư mục i18n gọn và tránh nhầm lẫn.

Script **`sync-docs-i18n.js`** có thể chỉ copy `.md`, `.mdx` và `_category_.json`, không copy `_category.json` và `_articles.json`.
